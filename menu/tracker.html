Tracker Help

The tracker adds up your entries over the last 4 weeks, 3 months, and 365 days. It counts today and every day before it, from the calendar and History, so an entry counts as soon as its day comes.

Rows And Aliases

  • Each row counts the entries its aliases point to. An alias is an entry title, set to count All of its amounts, only its Costs, or only its Gains.
  • In a row's panel, each alias has its own line: type the entry title, then pick All, Costs, or Gains. Typing a comma (or pressing Enter) starts the next one.
  • Rows leave out ⭕️ Transfers, since most transfers aren't real costs or gains. Turn on Also count ⭕️ Transfers for a row that should count them (its title then starts with ⭕️).
  • ✖️ Hidden entries always count, like any other entry, even ones for your Other Accounts.
  • A ⭕️ Transfer for an Other Account (like moving money into Savings) is still a transfer, so only rows set to count transfers count it.
  • If more than one row has the same alias, each of those rows counts it.
  • To see the entries behind a row, search for its title with its Tracker button in Home's (or History's) Search.

Search

🔎 Search (at the top, next to Edit) looks through the tracker's own rows: as you type, it lists the rows with every word you typed in their title or aliases (like "food" or "gas"). Tap a row it found to open it. × or Escape closes it.

Costs, Gains, And Undefined

  • Costs and Gains add up every cost and every gain (✖️ Hidden ones too), except ⭕️ Transfers. They fill in by themselves.
  • Undefined lists the entry titles that no row counts yet, and adds them up. ⭕️ Transfers never go there: a transfer only counts in a row set to count transfers. If you add an alias to a row but Undefined still lists it, the alias only counts Costs or only Gains, so entries of the other kind aren't counted yet. For example, if an alias for John counts Gains, costs titled John are still undefined.

Changing Rows

  • Tap New Entry to add a row, or tap a row to change or delete it. Tap Edit to drag rows by their ≡ bar, add sections (+ Section), or check rows and delete them. Costs, Gains, and Undefined come back if you delete them.
  • A title can have two rows: one that counts transfers (its title starts with ⭕️) and one that doesn't. If you add one that matches a title and transfer setting you already have, it says so, and you change the one that's there instead.
